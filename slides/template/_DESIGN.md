# 勉強会スライド デザインシステム

`slides/template/_TEMPLATE.md` から `.pptx` を起こすときの見た目の定義。
オレンジ × ベージュの勉強会向けデザイン。色やフォントを変えたいときはこのファイルと `slides/build/lib.js` の `C` / `DEFAULT_FONT` を書き換える。

---

## 1. キャンバス

| 項目 | 値 |
|---|---|
| スライドサイズ | 13.333 × 7.5 inch（16:9 / ワイド画面） |
| 左右マージン | 0.75 inch |
| 上マージン | 0.40 inch |
| 下マージン | 0.55 inch |
| 本文エリア | x=0.75〜12.58 / y=1.75〜6.60 |

## 2. カラーパレット

| 役割 | HEX | 使いどころ |
|---|---|---|
| `BG` 背景 | `#F2F0EB` | 全スライドの地色（オフホワイト／エクリュ） |
| `ACCENT` アクセント | `#E8491F` | 見出し罫線・番号・強調・セクション扉のベタ塗り |
| `ACCENT_SOFT` | `#E8825F` | 画像プレースホルダ、淡い面 |
| `INK` 本文 | `#1A1A1A` | タイトル・本文 |
| `INK_SUB` 補足 | `#6B6B6B` | キャプション・注釈・ページ番号 |
| `DARK` コード地 | `#1E1E1E` | コードブロック / ツリー図の背景 |
| `ON_DARK` | `#EDEDED` | ダーク面の文字 |
| `WHITE` | `#FFFFFF` | セクション扉・クロージングの文字 |
| `RULE` 罫線 | `#C9C5BC` | 目次の破線、カラム区切りの縦線 |

> **原則**: 1枚のスライドでアクセント色を使うのは「見出し罫線 + 強調1〜2箇所」まで。
> オレンジを多用すると全部が主役になって効かなくなる。

## 3. タイポグラフィ

| 用途 | フォント | サイズ | ウェイト | 色 |
|---|---|---|---|---|
| 表紙タイトル | Hiragino Sans | 44pt | Bold | INK |
| Eyebrow（小見出しラベル） | Hiragino Sans | 12pt | Bold | ACCENT |
| スライドタイトル | Hiragino Sans | 30pt | Bold | INK |
| セクション扉タイトル | Hiragino Sans | 36pt | Bold | WHITE |
| 見出し（■付き） | Hiragino Sans | 18pt | Bold | INK |
| 本文・箇条書き | Hiragino Sans | 15pt | Regular | INK |
| 第2階層の箇条書き | Hiragino Sans | 13pt | Regular | INK |
| キャプション・注釈 | Hiragino Sans | 11pt | Regular | INK_SUB |
| 番号（01/02/03） | Roboto / Helvetica | 24pt | Bold | ACCENT |
| コード・ツリー図 | Menlo / Roboto Mono | 12pt | Regular | ON_DARK |
| ページ番号 | Helvetica | 10pt | Regular | INK_SUB |

- 日本語フォントは macOS 標準の **Hiragino Sans** を既定にする（環境依存を避けるため）。
  チーム配布用に統一したい場合は `Noto Sans JP` に置換する。
- 1行の文字数は **全角30文字以内**。超えるなら文を割るか2枚に分ける。

## 4. 共通パーツ

### ヘッダー（`title` / `section` / `closing` 以外の全スライド）
```
Eyebrow      x=0.75  y=0.40  12pt Bold ACCENT     ← 章名や「基本機能 ①」など
タイトル      x=0.75  y=0.68  30pt Bold INK
オレンジ罫線   x=0.75  y=1.42  幅11.83  太さ3pt  ACCENT
```

### フッター
```
ページ番号    右下 x=12.40 y=6.95  10pt INK_SUB   ← 表紙は入れない
```

### 強調表現
- **オレンジ文字**: 結論のキーワードのみ（1枚に1〜2語）
- **オレンジベタ帯**: 「GOAL —」「結論 —」など、そのスライドの主張を1行で置く帯
  （高さ0.55in / 文字は WHITE 16pt Bold / 左パディング0.3in）
- **■ 見出しマーカー**: 0.12in の ACCENT 四角 + 半角スペース + 見出し文字

## 5. レイアウトカタログ

`//layout: <id>` で指定する。各IDの中身は下記。

### `title` — 表紙
- 背景 BG。右側に **半分見切れた ACCENT の正円**（直径 6.5in / 中心 x=11.0 y=3.75）
- 左上に Eyebrow（`STUDY SESSION — ○○` などのイベント名）
- タイトルは左寄せ・3行まで・44pt Bold
- ページ番号なし

### `message` — 大きな一言
- タイトルなし。中央やや上に 32pt Bold のメッセージを2〜4行
- キーワードだけ ACCENT
- 余白を大きく取る（詰め込まない）

### `agenda` — 目次
- 左に `CONTENTS`（28pt Bold ACCENT）+ その下に小さく `目次`（11pt INK_SUB）
- 右側 x=4.2〜12.3 に項目を縦積み。1項目 = `番号(01) + ACCENT縦棒 + 章タイトル`
- 項目間に **破線**（RULE / 1pt / dash）
- 5項目までは1画面に収まる。6項目以上なら文字サイズを1段落とす

### `section` — セクション扉
- **全面 ACCENT 塗り**
- 中央左に `番号(01) + WHITE縦棒 + 章タイトル(36pt Bold WHITE)`
- その下にサブコピー（16pt / WHITE 80%不透明）
- 左下に小さくイベント名（10pt Bold WHITE）

### `closing` — クロージング / 議論タイム
- `section` と同じ全面 ACCENT
- Eyebrow に `DISCUSSION` などのラベル
- タイトル32pt + 下に一言（14pt）
- **議論の時間など、文言だけで良い枚は装飾を足さない**

---

### ■ 画像を貼るパターン

### `image-right` — 左テキスト / 右画像
- テキスト: x=0.75 幅5.6 / 画像: x=6.9 幅5.7 高さ4.2（y=1.85）
- 画像下にキャプション（11pt INK_SUB）を置ける
- **用途**: 機能説明、スクショ＋解説

### `image-left` — 左画像 / 右テキスト
- 画像: x=0.75 幅5.4 高さ4.0 / テキスト: x=6.6 幅6.0
- 画像がロゴやアイコン的なときは `ACCENT_SOFT` の面の上に載せる
- **用途**: 概念の説明（左に象徴イメージ、右に定義と箇条書き）

### `image-full` — 画像1枚どーん
- ヘッダーだけ残し、画像を x=0.9 y=1.75 幅11.5 高さ4.6 で配置
- 画像内で注目させたい箇所には ACCENT の下線／枠を重ねる
- **用途**: GitHub や管理画面のスクショなど、細部を見せたいとき

### `image-3` / `image-4` — 横並び画像カード
- 3枚: 幅3.5 / 4枚: 幅2.6、間隔0.35
- 各カード = `番号(01) + 画像/アイコン(1.1in四方) + ラベル(15pt Bold)`
- カード間に RULE の細い縦線
- 下部にオレンジ罫線 + 一言まとめを置くと締まる
- **用途**: ツール紹介、選択肢の並列提示

---

### ■ 文章だけで説明するパターン

### `bullets` — 1カラム箇条書き
- x=0.9 幅11.5。第1階層 15pt / 第2階層 13pt（インデント0.35in）
- 行間 1.5。**7項目まで**。超えたら分割

### `two-col` — 2カラム（文章だけ）
- 左 x=0.75 幅5.5 / 右 x=6.9 幅5.5、間に RULE の縦線
- 各カラムの頭に `■ 見出し`（18pt Bold）
- **用途**: 「書くべき内容 / メリット」のような対比

### `numbered` — 01/02/03 の縦並び
- 1項目 = `番号(24pt Bold ACCENT) + 見出し(18pt Bold) + 矢印つき説明(14pt)`
- 3〜4項目。項目間 1.2in
- **用途**: 手順、やることリスト、活かし方

### `grid-4` — 2×2 番号グリッド
- 上部にオレンジベタ帯で結論を1行
- 4セル（幅5.5 高さ1.5）。`番号 + 見出し(16pt Bold) + 説明(12pt INK_SUB)`
- **用途**: 運用ルール、ポイント4つ

### `compare-2` — 角丸2カード比較
- カード: 幅5.3 高さ4.3 / 角丸0.25 / 枠線 ACCENT 1.5pt / 塗りなし
- カード頭にアイコン + 名称（20pt Bold）、下に ACCENT の短い罫線
- 中身は ✅ 付きの箇条書き（3項目まで）
- **用途**: A と B の使い分け

### `table` — 比較表
- ヘッダー行のみ下罫線 ACCENT、データ行は罫線なし（余白で分ける）
- 1列目 = 比較軸（左寄せ 12pt）、2列目以降 = ○/✕（中央寄せ）
- **重要な行だけ Bold** にして視線を誘導
- 10行まで。超えるなら軸を絞る

### `code` — コードブロック / ツリー図
- DARK の角丸矩形（x=0.9 幅11.5 高さ4.3 / 角丸0.1）
- 中は Menlo 12pt ON_DARK。ラベル（`PROJECT TREE` など）を ACCENT 11pt Bold で先頭に
- ツリーは `├─ └─ │` で描き、右側に日本語の説明を揃える
- 枠外の下に `NOTE —` の注釈（11pt / `NOTE` だけ ACCENT Bold）

### `diagram` — 中央→分岐のダイアグラム
- 上部にオレンジベタ帯で前提を1行
- 中央に ACCENT の親ボックス（幅1.6 高さ0.7 / WHITE文字）
- そこから ACCENT の矢印を3方向へ。子は `画像/アイコン + 名称(15pt Bold) + 役割(12pt ACCENT)`
- **用途**: 役割分担、処理フロー、たとえ話の図解

## 6. 迷ったときの選び方

| 伝えたいこと | レイアウト |
|---|---|
| 章が変わる | `section` |
| 概念を1つ定義する | `image-left`（左に象徴画像） |
| 画面や設定を見せる | `image-right` / `image-full` |
| 対比・トレードオフ | `two-col` / `compare-2` / `table` |
| 手順・やること | `numbered` |
| 並列の選択肢 | `image-4` / `grid-4` |
| 設定ファイル・構成 | `code` |
| 関係性・役割 | `diagram` |
| 主張を刺す | `message` |

## 7. 見やすさ重視のレイアウト（lib.js 拡張）

カタログ外だが `slides/build/lib.js` に入っている、文字を大きく濃く見せるためのレイアウト。
説明文が多いスライドは、上のカタログよりこちらを優先する。

| 関数 | 見た目 | 用途 |
|---|---|---|
| `cardGrid` | 白い角丸カード + オレンジ丸番号 + 15〜17pt の濃い本文。`foot` で下に一言 | 手順・ポイント・準備物 |
| `flowCards` | 大きなカードを矢印でつなぐ。`hi` 番目だけオレンジ塗り | 全体像・処理の流れ |
| `chips` | 黒いコード札 + 意味 | 記法・コマンドの早見表 |
| `phoneChat` | 左にスマホ風チャット、右にコツのカード | 使い方のイメージ |
| `quote` | 公式ドキュメントのスクショ + 要旨 + URL | 出典を見せる |
| `timeline` | 横一列の時系列 | 遍歴・ロードマップ |
| `custom` | ヘッダーだけ用意して自由に描く | どれにも合わないとき |
